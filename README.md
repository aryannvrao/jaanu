## 🚀 How to Host on GitHub Pages (Drag & Drop in 60 seconds)

### Step 1: Create a New GitHub Repository
1. Go to [github.com/new](https://github.com/new) in your web browser.
2. Enter a **Repository name** (e.g. `quiet-place` or `sanctuary`).
3. Make sure it is set to **Public** (required for free GitHub Pages).
4. Click **Create repository**.

---

### Step 2: Drag & Drop the Files
1. On the new repository page, click the link that says **"uploading an existing file"** (or click **Add file ➔ Upload files**).
2. Open this `make` folder on your computer.
3. Select **all files** inside this folder:
   - `index.html`
   - `.nojekyll`
   - `song.mp3`
   - `pal-pal-dil-ke-paas (mp3cut.net).mp3`
   - `aryan.jpeg`
   - `aryan eyes but he is on the right.jpeg`
   - `harshu.jpeg`
   - `harshu eyes.jpeg`
   - `us1.jpeg`, `us2.jpeg`, `us3.jpeg`
4. Drag and drop them directly into the GitHub upload box in your browser.
5. Scroll down and click the green **Commit changes** button.

---

### Step 3: Turn On GitHub Pages
1. In your GitHub repository, click **Settings** (top menu bar).
2. On the left sidebar, click **Pages**.
3. Under **Build and deployment** ➔ **Branch**:
   - Change `None` to **`main`** (or `master`).
   - Leave the folder as **`/ (root)`**.
4. Click **Save**.

That's it! In about 30 to 60 seconds, GitHub will give you your live URL:
`https://<your-username>.github.io/<repo-name>/`
